# Changelog

This crate uses the shared `hns-dane-engine` workspace version. Complete
release notes for every public crate are maintained in the repository-level
[`CHANGELOG.md`](https://github.com/handshake-rs/hns-dane-engine/blob/mobile-wallet-v0.2.6/CHANGELOG.md).

## 0.2.6 - 2026-09-28

Repins the coordinated mobile-wallet engine cohort to the coherent
`hns-rs 0.5.0` protocol release while retaining the existing public light-client
and browser-adapter behavior.

## 0.2.5 - 2026-09-23

Publishes the coordinated SQLite graph as part of the coherent mobile-wallet
engine release.

## 0.2.4 - 2026-09-23

Publishes the coordinated SQLite migration prepared on the 0.2.3 source line:
`rusqlite 0.40.2` and `libsqlite3-sys 0.38.2`, with no API or schema change.

## 0.2.3 - 2026-09-07

Advanced the shared SQLite dependency to `rusqlite 0.40.2` and
`libsqlite3-sys 0.38.2`. This is a dependency-only compatible patch with no
adapter API or persistence-schema change.

## 0.2.2 - 2026-08-23

This browser adapter first published on the `0.2.2` line retains its PolyForm
Noncommercial license. Its immutable source record is tagged
`browser-adapters-v0.2.2`. A source archive alone does not qualify a browser,
mobile adapter, live network path, wallet provider, or marketplace product.

## 0.2.0 - 2026-08-10

See the canonical workspace changelog for the complete shared release scope
and qualification status. A source archive alone does not qualify a browser,
mobile adapter, live network path, wallet provider, or marketplace product.
