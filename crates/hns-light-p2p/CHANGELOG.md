# Changelog

This crate is part of the compatible `hns-dane-engine` light-client patch
cohort. Complete release notes are maintained in the repository-level
[`CHANGELOG.md`](https://github.com/handshake-rs/hns-dane-engine/blob/mobile-wallet-v0.2.6/CHANGELOG.md).

## 0.2.6 - 2026-09-28

Repins the coordinated mobile-wallet engine cohort to the coherent
`hns-rs 0.5.0` protocol release while retaining the existing public light-client
and browser-adapter behavior.

## 0.2.5 - 2026-09-23

Carries the typed standard Handshake serving events forward while repinning
the complete public light-client type graph to `hns-rs 0.4.2`.

## 0.2.4 - 2026-09-23

Expose standard Handshake `GETADDR`, `GETBLOCKS`, and `GETHEADERS` requests as
typed peer events so an embedding mobile `NETWORK` listener can answer them
from its own validated, bounded address and chain state.

## 0.2.3 - 2026-09-01

Repinned the public light-client type graph to the coherent `hns-rs 0.4.1`
protocol cohort. `hns-light-sync` also adds safe abandonment of an uncommitted
header round while preserving authenticated chain state.
