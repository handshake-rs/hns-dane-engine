# hns-browser-chain

Durable validated Handshake header-chain adapter for browser runtimes. It
provides bounded header storage, proof-of-work and retarget validation, and
atomic canonical-tip publication for platform clients.

This crate is part of [hns-dane-engine](https://github.com/handshake-rs/hns-dane-engine).
